## The Short Answer

When you make a raster image bigger, the software has to **invent pixels that don't exist**. No matter how clever the algorithm, invented data is always an approximation. Edges blur, fine details smear, and the image loses sharpness. This is called **pixelation** or **interpolation softness**, and it is a fundamental physical limitation of fixed-resolution image formats.

The alternative — vector graphics — avoids this problem entirely because vectors don't store pixels at all.

---

## Part 1: How Raster Images Store Colour

A raster image is, at its core, a **two-dimensional grid of colour values**.

Imagine a spreadsheet with 4,000 columns and 3,000 rows. Each cell contains one colour value — a triplet of Red, Green, and Blue values from 0 to 255 (for 8-bit colour). A 4000 × 3000 image has exactly **12 million cells** (12 megapixels), each holding precisely one colour.

When you display this image on screen, each cell becomes one pixel on your monitor. When you print it, each cell is mapped to a region of ink on the paper.

### The crucial point: the grid is fixed

The number of columns and rows in that spreadsheet is permanently set when the image is created or captured. If you want to make the image physically larger, you have two options:

1. **Print at lower DPI** — spread the same pixels over a larger area (each pixel gets physically bigger, eventually becoming visible as squares)
2. **Upscale by adding more pixels** — use a software algorithm to invent new cells in the spreadsheet

Neither option recovers detail that was never there. The first option makes pixels visible. The second option blurs them.

<CalloutBox type="info" title="The Fundamental Raster Limitation">
  A raster image can only ever **display** detail that was captured when the file was created. Enlarging it never adds information — it only *distributes* the existing information over a larger area.
</CalloutBox>

## Part 2: What Actually Happens During Upscaling

When you drag the corner of an image in Photoshop to make it bigger, the software runs an **interpolation algorithm** in the background. Here's what that actually means:

### Step 1: Calculating the new grid size

If you scale a 1000 × 1000 pixel image to 200% size, the software needs a 2000 × 2000 grid. It now has to fill 4,000,000 cells where only 1,000,000 existed before. **Three out of every four pixels must be invented.**

### Step 2: Choosing an interpolation method

The software has to decide what colour each new pixel should be. It does this by looking at the surrounding original pixels and making a mathematical estimate. The three most common methods are:

**Nearest-neighbor interpolation** (fastest, worst quality)
The new pixel simply copies the colour of the nearest original pixel. The result looks blocky and pixelated — you can clearly see the square pixel grid. This method is occasionally used intentionally for pixel art.

**Bilinear interpolation** (medium quality)
The new pixel's colour is calculated as a weighted average of the 4 surrounding original pixels. This produces smoother edges than nearest-neighbor but can introduce blurriness, especially along diagonal edges.

**Bicubic interpolation** (best classical quality)
The new pixel is estimated from the 16 surrounding pixels in a 4×4 neighbourhood, using a more complex weighted curve formula. This is Photoshop's default. Bicubic produces the smoothest result of the classical methods, but still cannot reconstruct detail — it just blurs more smoothly.

**AI / Super-resolution upscaling** (modern best quality)
Machine learning models trained on millions of image pairs learn to predict what high-resolution detail *should* look like based on the low-resolution input. Tools like Adobe Firefly, Topaz Gigapixel AI, and Stable Diffusion upscalers produce dramatically better results, but they're still *predicting* rather than *recovering* original detail.

<CalloutBox type="warning" title="The Upscaling Trap">
  Some print shops and online print services will automatically upscale low-resolution images and send them to print without warning you. The result is a blurry print, and you've already paid. Always verify your pixel dimensions against the required output size **before** ordering.
</CalloutBox>

## Part 3: Understanding the "Blurriness Threshold"

At what point does an image actually look blurry in print?

The professional standard is **300 PPI** (pixels per inch) at final print size. Below this, the human eye begins to resolve individual pixels at typical reading distances (30–40 cm).

Here's a practical breakdown:

| PPI at Print Size | Quality | Use Case |
|---|---|---|
| 400–600 PPI | Archival / ultra-sharp | Fine art, medical imaging |
| 300 PPI | Professional print standard | Books, brochures, business cards |
| 200–250 PPI | Acceptable | Low-budget printing, flyers |
| 150–200 PPI | Noticeably soft | Draft proofs, newspaper |
| 72–100 PPI | Pixelated for close viewing | Posters viewed from 3+ feet, banners |
| Below 72 PPI | Clearly blurry/pixelated | Large-format signage at close range |

## Part 4: Vector Graphics — The Solution for Scalable Art

Vector graphics solve the scaling problem by completely changing how visual information is stored.

Instead of storing a grid of pixel colours, a vector file stores **mathematical descriptions of shapes**:

- A circle: centre point (x, y), radius r, fill colour #FF0000
- A line: start point (x1, y1), end point (x2, y2), stroke width 2px, colour #000000
- A curve: Bezier control points, tangent handles, fill colour

When you scale a vector image — whether from business-card size to billboard size — the software simply recalculates where those points and curves fall at the new dimensions. The output is always mathematically perfect, with no approximation.

### A real comparison

Imagine a company logo: the letter "A" in a bold sans-serif font.

**As a raster PNG at 200×200 pixels:**
- Scales up to 4000×4000 pixels → severely blurry edges, jagged diagonals
- Prints on a billboard → obvious pixelation

**As an SVG vector:**
- Scales up to 4000×4000 → perfectly crisp
- Prints on a billboard → perfect
- Scales down to 16×16 favicon → still readable (though manual optimization helps at very small sizes)

<CalloutBox type="tip" title="When to Use Each Format">
  **Use raster (JPEG, PNG, WebP) for:**
  - Photographs
  - Complex illustrations with gradients and photorealistic texture
  - Screenshots
  - Any image where photographic detail is the content

  **Use vector (SVG, AI, EPS) for:**
  - Logos and brand marks
  - Icons
  - Geometric illustrations
  - Charts and diagrams
  - Any artwork that must appear at many sizes
</CalloutBox>

## Part 5: The Physics of Pixelation — Why Edges Suffer Most

Pixelation is most visible along **diagonal and curved edges**. Here's why.

A horizontal or vertical line in a raster image aligns neatly with the pixel grid. Every pixel in the row is the same colour, and the boundary is sharp. When you scale this up 2×, each pixel becomes 2×2 pixels — still a sharp edge.

A diagonal line does not align with the grid. A 45° diagonal must be approximated with a staircase pattern of pixels — what typographers call a "jagged" edge or programmers call "aliasing". This is already an approximation at the original resolution.

When you upscale a diagonal edge, the staircase pattern becomes larger and more visible. Interpolation smooths it slightly by making the edge pixels partially transparent (anti-aliasing), but it cannot make a staircase into a mathematically smooth line.

**This is why raster logos always look bad when printed large** — logos are full of curves and diagonals.

## Part 6: What About AI Upscaling? Does It Actually Recover Detail?

Modern AI upscaling tools have dramatically improved the quality of raster upscaling. Tools like:

- **Adobe Firefly Enhance** (in Photoshop)
- **Topaz Gigapixel AI**
- **Real-ESRGAN** (open source)
- **waifu2x** (specialised for anime/illustration)
- **Stable Diffusion img2img** with high denoising

...can often produce results that look indistinguishable from genuinely higher-resolution originals, especially for faces, textures, and architectural details.

### But there's a fundamental limit

AI upscaling is **hallucination**, not recovery. The model is generating plausible detail based on patterns learned from training data — not reconstructing what was actually in the original scene.

For creative and personal use, this is excellent. For scientific, medical, forensic, or archival purposes, AI-upscaled images **must never be used as source material** — the added detail is fabricated.

<CalloutBox type="warning" title="AI Upscaling ≠ Real Resolution">
  If you need a 24×36 inch poster from a 500×500 pixel source photo, AI upscaling will produce *a* result — but it will not be your photograph at that resolution. It will be an AI's interpretation of what your photograph might look like at that size. For personal use, this is often fine. For professional, commercial, or archival contexts, always capture at sufficient resolution from the start.
</CalloutBox>

## Part 7: Practical Workflow — How to Avoid the Quality Drop

### Rule 1: Always start at sufficient resolution

For print: create your canvas at the final print size × 300 PPI from the very beginning.

For a 4×6 print → start at 1200×1800 pixels.
For a letter-size poster → start at 2550×3300 pixels.

If you start at 800×600 and want to print 8×10 at 300 DPI, you will need 2400×3000 pixels — and you simply don't have them.

### Rule 2: Scale down, not up

Always work at the largest size you'll ever need, then scale down for smaller uses. Downscaling (reducing pixel count) loses very little perceptible quality because you're averaging real data. Upscaling (adding pixels) invents data.

### Rule 3: Keep source files in native formats

- Photoshop: keep `.PSD` files with all layers intact
- Illustrator: keep `.AI` files for vector artwork
- Camera: shoot RAW, not JPEG — RAW preserves maximum pixel data

### Rule 4: Know your output before you start

Before opening a new document, ask:
1. What is the final print/display size?
2. What DPI is required?
3. What colour mode (RGB for screen, CMYK for print)?

Calculate: `pixels = inches × DPI` → that's your canvas size.

## Key Takeaways

- Raster images are fixed pixel grids. Enlarging them requires inventing pixels, which always blurs edges.
- **Bicubic interpolation** is the best classical method; AI upscaling can produce impressive results but invents rather than recovers detail.
- The professional print standard is **300 PPI** at final output size.
- Vector graphics (SVG, AI, EPS) scale to any size without quality loss — they should be the default for logos, icons, and geometric illustrations.
- The most effective way to avoid pixelation is to **start at the correct resolution** for your largest intended use.
